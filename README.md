# 똑같은 말 100번 반복하지 마세요

오늘도 "가격 얼마예요?" 똑같은 질문 30번 받으셨죠? 일하다 말고 30번 답하셨죠?

사장님 대신 24시간 답해주는 **AI 직원** 데모입니다.
챗봇이 대신 답해드려요. 사장님은 편하게 본업만 하세요.

## 왜 만들었는가

> "높은 가치는 느끼는 사람들에게 전달되어야 한다"

사장님은 매일 같은 질문에 답하느라, 정작 중요한 일에 쓸 시간을 잃고 계셨어요.
그 시간을 돌려드리려고 만들었어요.

- **사람을 사람으로**: 손님도 사장님도 숫자가 아니에요. 한 분 한 분의 시간을 아껴드려요.
- **정직**: 모르는 건 모른다고 말해요. 안 되는 예약은 안 된다고 안내해요.
- **다크패턴 금지**: 몰래 결제 유도 같은 건 절대 없어요.
- **따뜻함**: "편하게", "안심하세요"가 기본 말투예요.
- **신뢰**: 받아낸 예약은 하나도 빠뜨리지 않고 전달해요.
- **겸손**: AI는 사장님의 보조일 뿐, 주인공은 언제나 사장님이에요.
- **인내**: 같은 질문 100번에도 지치지 않아요.

**이 데이터는 10년 후에도 사장님의 것입니다.**
AI 직원이 답한 질문과 받아낸 예약 기록은 가게의 자산이에요.
언젠가 가게를 물려주는 날, 그 노하우가 함께 이어지길 바랍니다 — **가게 이어받기**.

**사명 선언문**: "우리는 사장님의 일을 세상이 알아주게 만듭니다."

## 이런 사장님께

- "가격 얼마예요?", "예약 가능해요?", "어디예요?" — 같은 말 하루에도 수십 번 반복하시는 분
- 일하다 말고 답변하느라 본업에 집중 못 하시는 분
- 밤·주말에 오는 전화를 놓쳐 예약을 흘리신 적 있는 분
- 동네 청소업체·미용실·네일샵·이사/용달 사장님 (1인~소규모 매장)
- 목표 단가: **200~500만원** (초기 세팅 + 월 관리형 패키지)

## 실행 방법

```bash
cd ~/workspace/daangn-portfolio/06-ai-receptionist
./run.sh
```

- 첫 화면: http://localhost:5006/ ("어떤 가게세요?"에서 업종 선택)
- 손님용 채팅: http://localhost:5006/chat
- 사장님 관리 화면: http://localhost:5006/admin
- 5006번 포트가 이미 쓰이고 있으면 5007, 5008… 순으로 자동 전환됩니다.
  (실행 메시지에 실제 포트가 표시됩니다.)
- 종료: `Ctrl+C`

## 업종별 프리셋 (첫 화면에서 선택)

| 가게 | 준비된 것 |
|---|---|
| 🧹 청소업체 | 입주청소·정기청소 가격표(평수별), "청소 시간 얼마나 걸려요?" 같은 질문 |
| 💅 미용실·네일샵 | 컷·염색·펌·네일 시술별 가격, "디자이너 지정 돼요?" 같은 질문 |
| 🚚 이사·용달 | 거리·평수별 견적 안내, "당일 추가 요금 있나요?" 같은 질문 |

가게를 고르면 챗봇의 가격표·질문·용어가 그 가게에 맞게 바뀝니다.
(예: 미용실에서는 "어떤 시술로 예약할까요?", 이사 업체에서는 "어떤 이사로 예약할까요?"라고 물어봐요.)

## 사장님께 보여줄 포인트 (3분 시연)

1. 첫 화면의 **짜증 계산기** — "하루에 똑같은 질문 몇 번 받으세요?"를 움직여보세요.
   한 달에 몇 시간, 몇 만원을 쓰고 계신지 숫자로 보여줘요.
2. **"5분 안에 직접 써보세요"** — 누르자마자 가게를 골라 바로 체험돼요. 질문→답변까지 2클릭이면 충분해요.
3. `/chat` → "이사청소 32평 얼마예요?" → 가격표 그대로 답하는 걸 확인하세요. 밤 12시에도 이렇게 답해줘요. 걱정 마세요.
4. "예약하고 싶어요" → 날짜·시간·이름·연락처를 하나씩 여쭤보고 예약 접수까지 끝내요.
   전화를 못 받아도 예약은 흘러가지 않아요. 안심하세요.
5. "달나라에도 출장 가세요?" 같은 엉뚱한 질문 → "사장님께 직접 여쭤볼게요"라며
   손님 연락처를 받아둬요. 어려운 건 사장님께 바로 넘겨드리니 걱정 마세요.
6. `/admin` → **오늘 브리핑**에서 "오늘 AI가 답한 질문 N건, 아낀 시간 M분"을 확인하세요.
   못 답한 질문에 답변을 달아두면, 다음부터 AI 직원이 대신 답해요.
7. `/admin` → 가격표를 고치면 손님 채팅 답변이 **바로** 바뀌어요. 편하게 직접 바꾸세요.

## 기술 구성 (사장님은 몰라도 돼요)

- Python Flask + SQLite — 외부 AI를 쓰지 않아 요금 걱정 없고, 엉뚱한 답을 지어내지 않아요
- 우리 가게 자료(가격표·영업시간·자주 묻는 질문)로만 답해요
- 한국어 UI, 모바일 반응형 (손님은 폰으로 물어보니까요)
- 무슨 일이 생겨도 손님에게는 친절한 안내만 보여줘요

- 관리 화면 가격 변경 → 챗봇 답변 즉시 반영
